## Технические требования и схемы

Полное техническое задание находится в [TASK.md](../TASK.md), JSON-форматы — в [contracts/course-1](../contracts/course-1). Документы выше сгруппированы по компонентам и задачам эксплуатации. Технические контракты основаны на исходном задании с commit `e1ae7e03c6a4f2da5dc2ee9f02ebe3f26b2d16a3`.

При расхождении текста с JSON Schema для формы JSON действует schema. Совместимость ранее опубликованных контрактов сохраняется, кроме явно описанных в ТЗ расширений. Порядок автоматической подготовки checkers и закреплённые версии приведены в [разделе проверки](../README.md#проверка).

Архитектурные решения объясняют реализацию, а runbook — порядок диагностики и восстановления. Состав проверок и ограничения их результатов описаны в [testing.md](testing.md).
